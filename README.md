# Summery of this project

This task tracker api where user can register, login and can create and can add task to project with crud operation on task.

## How to use

## Tech Stack

Node.js, Express.js and MongoDB

---

## :rocket: Getting Started

1. Clone this repository;
   `https://github.com/Ritesh9919/task_tracker`

2. Navigate to project directory using `cd folder name`.

3. run `npm install`

4. run `npm run dev`
